# Idea Orbit

Idea Orbit is a simple project-idea generator for hackathons, events, and brainstorming sessions. Spin a colorful wheel to get a random project prompt, or choose a theme first to get an idea from a specific area. Each prompt includes a short description and a suggested first step to help you start building.

The wheel covers nineteen themes, including climate, health, learning, community, productivity, video games, art and design, music, travel, science, pets, sports, photography, robotics, home projects, and the outdoors. It includes 19,980 built-in ideas. The complete collection is available in [`idea-library.html`](./idea-library.html), and the app works without an internet connection or an AI service.

## Run it

Open `index.html` in a modern web browser. No other files, installation, or build step are needed.

## How to use it

1. Leave the theme picker on **Surprise me** for an idea from any theme, or select a theme to focus the wheel.
2. Select **Spin** to reveal a project idea.
3. Read the idea description and first step, then select **Copy idea** to copy it.
4. Spin again whenever you want another prompt.
5. Select **Browse idea library** to search and filter the full collection by category.

Open `idea-library.html` to browse the standalone searchable collection. The **Idea library link** in the main app currently points to `about:blank` as a placeholder for a destination you will configure later.

## Features

- Nineteen themes with 19,980 built-in project prompts
- Animated spins that land on the theme used for the selected idea
- Searchable idea library with category filters and paginated results
- Random or theme-specific spins
- Copy the selected idea to the clipboard
- Responsive layout and reduced-motion support
- 19,980 runnable project examples under [`Examples/`](./Examples/), organized by theme and idea
