# Idea Orbit

A project-idea wheel for hackathons, events, and brainstorming sessions.

## Run it

Open `index.html` in a modern web browser. No installation or build step is needed.

## Features

- Fourteen themes with 116 built-in project prompts, including twelve video-game ideas
- Random or theme-specific spins
- Copy the selected idea to the clipboard
- Responsive layout and reduced-motion support
