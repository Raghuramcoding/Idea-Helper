# Idea Orbit Examples

Standalone, runnable HTML prototypes for project ideas, organized by category and idea-name folder. Each project page includes the idea description, an interactive example, and the suggested first step. Examples run offline and do not send entered data anywhere.

## Batches

- Batch 1: the first quarter of each category, rounded down — 4,991 examples.
- Batch 2: the next 4,993 ideas, allocated proportionally across categories.
- Batch 3: all remaining ideas — 9,996 examples.
- Total: all 19,980 ideas now have examples.
